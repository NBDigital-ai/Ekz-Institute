# English Kids Zone Institute

Landing page estática (HTML/CSS/JS) de la escuela de inglés online. Se publica con GitHub Pages desde la rama `main`.

## Pendientes para activar
- **Formulario**: crear cuenta en [formspree.io](https://formspree.io) con el correo de la escuela y sustituir `FORMSPREE_ID` en `index.html`.
- **WhatsApp**: sustituir `52XXXXXXXXXX` por el número real (con lada de país) en el enlace del pie de `index.html`.

## Portales
`maestro.html`, `alumno.html` y `padres.html` son páginas de "próximamente" que describen lo que tendrá cada rol. El portal real (cuentas, tareas, calificaciones, pagos) se hará como proyecto aparte y se enlazará desde el menú.

## Ver en local
```
python -m http.server 8765
```
y abrir http://localhost:8765
